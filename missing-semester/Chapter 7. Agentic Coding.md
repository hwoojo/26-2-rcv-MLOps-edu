# How AI models and agents work
일단 LLM이 어떻게 돌아가는지를 좀 알아야 한다

LLM은 기본적으로 어떤 단어 / 문장이 오면 그런 텍스트를 가지고 이 다음에 올 말을 예측하는 그런 구조로 돌아간다. 또한 context windows라는 개념을 가지면 좋다. 제한적인 context windows 를 가지고 있음을 알면 좋음. 

이걸 알려면 멀티턴 채팅에 대해 좀 살펴봐야 한다.

예시를 들어보자
```
user: what is one plus one?
assistant: it is two.
user: what is two minus one then?
assistant: it is one.
```
이런 식이 있다고 하면, AI는 기본적으로 이런 어떤 문장이 온다면 이 다음 올 문장을 예상해서, 그런 추론을 가지고 뭔가 결과물을 내는 것이다.

이제 하네스에 대해 알아보자.

물론 인공지능이 텍스트로 된 단어를 내뱉을 수도 있겠지만, 요즘 에이전트는 Tool call이란 걸 하기도 한다. 기본적으로 인공지능이 어떤 명령어, 어떤 걸 실행하고 나온 결과물을 자기의 인풋에 함께 추가하는 형태다. 

학생질문 3
Q. 하네스란 게 그래서 뭐냐?
A. 앞에서 말한 것과 같이 어떠한 도구를 호출하고, 거기서 나온 아웃풋을 다시 또 인풋으로 이용해서 뭔가를 쓰는 것이다. 만약에 인풋에 어떤 도구를 사용하란 게 있으면 도구를 실제로 불러와서 실행하고, 거기서 나온 결과물을 다시 또 인풋으로 넣어서 추가적으로 아웃풋을 뽑아내는 것이다.
예시를 들자면
코딩 에이전트에게 다양한 도구가 있을 수 있다. Bash, File Read, write... 이런 기본적인 작업을 할 수 있는 도구들이 있는 것이고 이걸 이용하게 하는 것이 하네스다.

그래서 에이전트들에겐 이런 도구들을 호출하고, 루프를 돌려가면서 결과를 얻고, 이걸 또 이용하는 그런 구조가 달린 것이다.
