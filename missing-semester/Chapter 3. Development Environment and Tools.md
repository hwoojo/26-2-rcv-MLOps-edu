# Language Server
vscode를 설치해봤으면 알겠지만 IDE를 설치한다고 모든 언어를 다 해석해서 다 돌릴 수 있는 건 아님
IDE는 language server과 연결되게 됨. LSP 프로토콜이란 걸 중간에 연결이 된다고

위에 vim은 좀 알만하니까 그럭저럭 넘어가지만 얘는 좀 더 짚고 넘어가자면

그럼 이 language server가 하는 일은 무엇이 있는가
- 뭐 코드 이런 거 적으면 auto completion을 해줌. 뭐 우리가 코딩할 때 printf 같은 거 적을 때 pri... 까지만 적어도 자동 완성이 되는 것처럼
- 뭐 이게 뭐하는 함수인지 찾는 것도 language server가 하는 일이고
- 이런 거 덕분에 코드 퀄리티가 전체적으로 나아진다는 것인듯?
