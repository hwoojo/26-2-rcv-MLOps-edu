- `256 → 128 → 64` : 정보를 압축하면서 중요한 특징을 뽑겠다는 느낌

- `256 → 512 → 256` : 더 넓은 공간에서 여러 특징 조합을 만들어 보겠다는 느낌
- `256 → 1024 → ...` : 모델 표현력은 커지지만 파라미터와 과적합 위험도 크게 증가
