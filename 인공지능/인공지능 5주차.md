# Learning rate
gradient descent를 하면서 보폭 = learning rate

너무 크면 발산해버림 => loss가 NaN이 되어버림 = overshooting이라 함
너무 작으면 오래 걸림 => local minima인가 그 문제도 있고

그럼 어떻게 적합한 값을 얻느냐
실험적으로 얻는 수밖에 없다

# Data preprocessing

근데 lr은 모든 가중치에 동일하게 적용하니까 뭐 얘는 이정도 쟤는 저정도 이런 식으로 lr을 결정할 수가 없고

그래서 정규화되지 않은 데이터를
1. zero-centered data로 만들고

# overfitting
과적합? 

모델이 주어진 데이터에만 잘 반응하려고 하는 것 = 과적합
=> 그러면 테스트 데이터에선 성능이 별로가 되어버린다

학습 데이터에만 성능이 좋으면 일반화가 되지 않아서 사실상 학습을 한 의미가 없겠지

그럼 overfitting이 되었는지 어떻게 아는가
학습 데이터는 잘 하는데 테스트 데이터 성능은 안 나올 때

그럼 좋은 모델은?
두 데이터셋에서 모두 좋은 성능이 나오는 상황

# Solution for overfitting
- 학습 데이터를 늘리기
- feature을 줄이기 
- regularization, 규제화

사실 2번도 나한테 중요하지 않을까 싶음. 데이터 사이언스한 이야기지만. 데이터 사이사이의 상관관계를 생각한다든가 해서

# Regularization
목적이 뭐냐 하면 W 값이 너무 커지지 않게 잘 제어하는 것에 있음
-> overfitting을 피하기 위한 거임

loss에 정규화를 하는 게 수학적으로도? 나이스하게 제어해주니까

# Performance evalulation

단, 평가에선 학습에 들어가지 않은 데이터만이 들어가야 함
