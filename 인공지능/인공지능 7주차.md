# Activation Function
신경학적으로는 뉴런 발사하는- 뉴런 투 뉴런 정보 교환을 할 때 쓰는 애임

우리가 이태까지 쓴 건 시그모이드

좀 보자면

1. step function
입력이 양수면 1 음수면 0
근데 미분을 못 함... 계단 형태니 기울기가 없지
그래서 이제는 못 씀 -> 역전파를 못 하니까

2. sigmoid
입력을 0 1 사이로 정규화
근디 미분값이 작음... 결코 1을 넘지 않기 떄문에 점점점 작아짐 = 기울기 손실
그래서 deep layer (3개 이상)이라면 별로 추천하지 않음

3. tanh
시그모이드보다 성능이 전반적으로 좋음
물론 기울기 손실은 발생함 (시그모이드보단 덜 발생함)

4. ReLU
가장 인기가 많다
음수다 = 0
양수다 = 그 양수 그대로

그럼 미분 값이 0 또는 1의 값을 가져서 기울기 손실 문제를 해결함
수학적으로도 exp가 없어서 sigmoid나 tanh함수보다 더 빠르게 학습이 진행됨

그럼 단점은?
살짝 살짝의 단점이 있어서 Leaky ReLU, ELU 같은 애도 나왔음

5. Leaky ReLU
이게 음수면 무조건 0으로 되어버리니까 문제가 있었음
그래서 0 말고 작은 기울기를 씀
이게 성능 향상이 발생하는 때도 있는데 아닐 때도 있음

6. ELU
exponential-LU
thereshold를 -1로 낮춤
이것도 dying relu를 해결하려고
근데 exp연산이 없어서 빠르다는 장점이 사라져버림

7. maxout
ReLU Leaky ReLU를 일반화. ReLU가 갖는 장점을 모두 가지며 dying reLU도 해결
근데 파라미터가 두배라 메모리 사용이 늘어남. 연산이 늘진 않고...

그래서 이젠
ReLU를 써
그래도 좀 뭔가 부족해 보임 leaky, maxout, elu 등등을 써 (물론 무조건 나아지는 건 아니고)
