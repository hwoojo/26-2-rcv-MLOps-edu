# 01 함수의 개념과 활용
함수가 뭐임
y = fx?
입력값 x에 대한 출력값 y를 나오는 거니까
프로그램 또한 이런 식으로 어떤 입력값을 받고 아웃풋을 내보내는 것
프로그램의 품질과 신뢰성을 높이고 유지보수 비용을 절감할 수 있음

```python
def sum(num1, num2):
	print(f"첫번째 숫자: {num1}")
	print(f"두번째 숫자: {num2}")
	
	return num1 + num2
```
라면은
`def`은 함수 선언, `sum`은 함수 이름, `num1, num2`는 매개변수, `print`문들은 본문, 그리고 `return num1 + num2`는 반환값임.

- 들여쓰기로 기존 코드와 구분
- 매개변수가 없어도 되고
- 반환 값도 없어도 됨
- 함수 정의로는 실행되지 않고 호출해야 하고 `sum(1,2)`처럼 
	- 사실 뭐 print도 함수 input도 함수 다 함수니까
- 동일한 함수명으로 정의하면 함수가 재정의 되고
- 함수가 반환되면 종료됨

함수를 써야하는 이유는
- 코드의 재사용성 증가
- 가독성 향상
- 유지 보수성 향상
- 재귀호출

# 02 함수 매개변수와 반환

## 기본 매개변수
- 함수를 호출할 때 매개변수를 제공하지 않으면 자동으로 할당하는 값
- 함수를 유연하게 사용할 수 있음
- 매개변수 명 = 기본값 형태로 정의
- 기본 매개변수는 일반 매개변수 뒤에 위치
```python
def print(text = "no input"):
```
처럼 써서 기본 값을 지정해줄 수 있다.

- 기본 매개변수 사용 시 가변 객체 (리스트, 딕셔너리...)가 변조될 수 있음
	- 가변 객체를 기본 매개변수로 사용할 경우 함수 내부에서 생성하도록 구성
```python
def process_data(data, options = None):
	if options is None:
		options = {
			"name": "Unknown"
		}
```
이렇게 써야 한다고

## 키워드 인자
- 함수 호출 시 인자와 매개변수는 위치에 의해 연결됨
	- 위치 인자
- 키워드 인자: 함수 호출 시 인자에 매개변수 이름을 넣어 전달
	- 인자와 매개변수의 연결을 명확히 보여줄 수 있음
	- 매개변수의 순서에 영향을 받지 않으므로, 보다 유연하게 구성할 수 있음
- 키워드 인자와 위치 인자 혼용하여 사용
	- 키워드 인자는 위치 인자 뒤에 위치해야 함
- 코드의 가독성을 향상시키고 함수 호출을 명확하게 함

```python
def greet(name, greeting):
	print(greeting, name)
	
greet(name = "Alice", greeting = "hello")
greet(greeting = "Hi", name = "Bob")
```
이런 식으로 아래 한 것처럼 명시적으로 넣을 수 있다 
순서가 뒤집어져도 이런 식으로 적으면 상관 없다

## 가변인자
- 여러 인자를 유연하게 처리할 수 있게 활용
- 함수 정의에서 매개변수 이름 앞에 `*`을 붙여서 정의
- 튜플로 묶여서 전달됨
```python
def add_numbers(*args):
	result = 0
	for num in args:
		result += num
	return result
```
- 원하는 만큼의 인자를 전달할 수 있음
- 다른 매개변수와 함께 사용할 수 있으며, 일반 매개변수 뒤에 위치해야 함
- 하나만 정의 가능

## 키워드 가변 인자 리스트
키워드와 가변 인자를 섞어
- 여러 인자를 유연하게 처리할 수 있게 활용
- 함수 정의에서 매개변수 이름 앞에 `**`을 붙여서 정의
- 딕셔너리로 묶여서 전달됨
```python
def add_numbers(**args):
```
약간 딕셔너리를 넣는다고 생각하면 쪼금 더 편할듯

모든 매개변수 뒤 가장 뒤에 있어야 함

## 기타
- 함수 내에서 변수를 정의하면 함수 밖에서 사용할 수 없음
- 함수 밖에서 변수를 정의하면 함수 안에서 사용할 수 있음
- 함수 위에 전역 변수로 선언하면 어디에 있든 가능
- 특정 함수 내에 만들면 지역 변수로 선언하는 형태이므로 함수 내부에서만 접근이 가능함

# 03 모듈과 패키지
- 파이썬 정의와 문장을 담고 있는 .py파일
- 함수 변수 클래스 등등을 포함
- 모듈을 통해 코드를 구조화하고 유지보수하기 용이해짐
- 작성된 모듈은 다른 프로그램에서 재사용 가능

## 모듈 사용하기
- 모듈 생성하기: .py 파일에 정의
- 모듈을 다른 프로그램에서 가져와 사용하기
	- import '모듈명'
	- 모듈 내에서 다른 모듈을 가져오는 것 또한 가능
- 모듈의 이름: `__name__`으로 참조 가능

## 모듈 가져오기
-> 지역 네임스페이스를 가져옴
- `from 모듈명 import 개체명, 개체명2`로 모듈 전체가 아니라 개체만 가져오기 가능
- 이렇게 가져오면 해당 개체 이름을 바로 사용할 수 있고
- `from 모듈명 import *`
	- 으로 모듈 내 모든 개체를 import 해올 수 있음 (`_`으로 시작하는 것 제외)
	- 의도와 다르게 모듈 내 모든 정보를 가져오기 때문에, 잘 판단하고 써야 함!
위랑 뭐가 다르냐) 위에는 쓸 때 `math.add`같이 쓴다면 여긴 그냥 `add`로 쓰게됨

## 모듈 활용하기
- 모듈로서 코드와 메인 프로그램으로서 코드를 어떻게 구분할 수 있을까?
- `if __name__ == "__main__":`
- 파이썬 인터프리터로 실행한 파일은 모듈명이 `__main__`으로 고정됨

## 패키지란?
- 모듈의 계층구조를 만드는 방법
- 모듈을 계층화하고, 모듈을 포함하는 디렉토리의 집합
- 디렉토리 구조를 활용하여 연관성 있는 모듈을 그룹화하고 정리할 수 있음
- 코드의 구조화와 재사용을 용이하게 만들며, 대규모 프로젝트에 필수적으로 사용됨

- 패키지 바깥에서 모듈 임포트하기: `import package.module`
	- 실제 모듈을 활용 시: `package.module.function()`
- 별칭 이용하기: `import package.module as alias`
	- `alias.function()`
- 패키지 내의 모든 모듈 임포트하기: `from package import *`
	- 허용된 모듈만 가능

## 패키지 초기화
- `__init__.py`
	- 이 디렉토리가 파이썬 패키지임을 알려주는 파일
	- 패키지 수준에서 사용되는 변수, 함수, 또는 초기화 로직이 정의됨
	- 하위 모듈을 미리 로드하거나, 전역변수를 정의하는 등
	- `__all__`을 활용하여, 참조하게 만들 모듈만 선택 가능

# 04 파이썬의 라이브러리
잘 정의된 인터페이스를 갖춘 언어로 작성된 특정 동작의 구현 집합
- 표준화된 프로그램 요소를 재사용할 수 있음
- 여러 모듈과 패키지의 모음
- 특정 작업을 수행하기 위한 함수 클래스 상수 등의 모음
- 라이브러리는 여러 패키지들의 묶음으로 구성되며 패키지는 여러 모듈의 묶음으로 구성
- 표준 라이브러리: 파이썬 설치 시 기본으로 제공됨
- 외부 라이브러리: 다양한 회사, 개발자들이 제작하여 제공

## 파이썬 표준 라이브러리 
- 파이썬 인터프리터에 포함되어 설치
- 프로그래밍에 필요한 기본적인 기능을 제공
- 내장형, import 필요 없음
- 외 다양한 표준 라이브러리
	- random, math, datetime, os... 

## 파이썬 외부 라이브러리 활용하기
- 필요한 라이브러리 설치하기: pip
- `python -m pip install {package name}`
	- `python -m pip install somePackage==1.0.4` 로 특정 버전
	- `python -m pip install somePackage>=1.0.4`로 최소 버전

- 라이브러리 버전 관리하기: requirements.txt
	- 어떤 라이브러리와 버전을 사용하는지 정확히 설정
	- 외부 라이브러리의 업데이트에 우리 프로젝트가 영향을 받지 않도록 
- 얘는 `import {library_name}`으로 사용

- 기본 설치: 모든 개발환경에 공통적으로 설치됨
- 가상 환경: 해당 프로젝트에서만 사용되는 패키지 설치
	- 여러 프로젝트를 동시에 개발할 때, 의존성 충돌을 막을 수 있음
