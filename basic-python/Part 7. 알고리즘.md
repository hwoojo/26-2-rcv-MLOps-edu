# 01. 알고리즘 소개
알고리즘이란? 
어떤 문제를 해결하거나 계산 시 수행되는 명확한 명령문의 나열

알고리즘의 핵심은 "초기값"이 주어지고 유한한 시행횟수를 거쳐 "출력"을 함

## 알고리즘의 특징
1. 입력과 출력
	1. 입력값을 받고 결과를 출력, 입력데이터에 성능 비례
2. 유한성
	1. 유한한 단계로 실행됨, 무한루프에 빠져선 안 됨
3. 정확성
	1. 입력값에 대한 정확한 결과, 원하는 목표의 달성
4. 효율성
	1. 가능한 빠르고, 공간 효율적

## 알고리즘을 공부해야 하는 이유
- 문제해결 능력
- 효율적인 프로그래밍
- 문제 예측과 예방
- 프로그래밍 언어 이해
- 면접과 채용...?
# 02. 알고리즘의 복잡도
시간 복잡도, 공간 복잡도가 있고 둘 다 Big-O로 표기가 됨.

## 복잡도 - $O(n)$
- 입력 크기에 비례하여 선형적으로 시간, 공간 복잡도가 증가
- 최악의 경우, 입력된 데이터를 모두 순회해야 함
- 예시) 일반적인 배열에서 데이터 찾기
- 예시)동일한 배열 복사하기
순회 같은 게 보통 O(n)

## 복잡도 - $O(n^2)$
- 입력 크기의 제곱에 빌하여 시간, 공간 복잡도가 증가
- 데이터셋이 커질수록 불리해짐
- 중첩된 반복문을 사용하여 정렬하는 경우

## 복잡도 - $O(\log n)$
- 입력 크기에 따라 로그 형태로 시간, 공간 복잡도가 증가
- 큰 데이터셋에서 빠른 처리가 필요한 경우 선호됨
- 이진 트리 검색 등

# 03. 정렬 알고리즘
어떤 주어진 목록을 순서대로 정렬
## 버블 정렬
- 가장 간단하지만, 비효율적인 정렬 방식
1. 첫 번째 원소부터 시작하여, 인접한 두 원소를 비교
2. 앞의 원소가 뒤의 원소보다 크면 순서를 변경
3. 이 과정을 처음부터 끝까지 반복, 위의 과정으로 가장 큰 원소가 제일 오른쪽에 위치
4. 모든 원소가 정렬될 때까지 반복

## 삽입 정렬
- 손에 들고 있는 카드를 정렬하는 것과 유사한 방식
1. 두 번째 원소부터 키로 지정
2. 키의 앞 리스트에서 해당 키가 삽입될 위치를 탐색
3. 삽입될 위치를 찾으면, 키보다 큰 원소들을 한 칸씩 밀어내고 해당 위치에 키를 삽입
4. 위의 과정을 모든 요소가 정렬될 때까지 반복

## 퀵 정렬
- 분할-정복 알고리즘
1. 배열을 둘로 나눌 기준(피벗)을 결정
2. 피벗보다 작은 값들을 왼쪽 배열에, 큰 값을 오른쪽 배열에 저장
3. 왼쪽 배열과 오른쪽 배열을 대상으로 위의 과정을 반복 수행
4. 왼쪽 배열 + 피벗 + 오른쪽 배열

# 05. 다양한 알고리즘
- 검색 알고리즘
	- 선형 검색
	- 이진 검색
	- 해시 테이블

- 문제 해결을 위한 알고리즘
	- 무차별 대입 (Brute Force)
	- 분할 정복 (divide and conquer)
	- 백트래킹 (back tracking)
	- 동적 계획법 (Dynamic programming)
	- 재귀 (recursion)

## 무차별 대입(Brute Force)
- 문제의 모든 가능한 해를 생성하고, 계속하여 대입하여 해를 찾음
- 단순하고 직관적인 방법으로 특별한 배경지식을 필요로 하지 않음
- 문제의 범위가 크거나 가능한 해의 종류가 많을 수록 효율이 떨어짐
- 모든 경우의 수를 고려

## 분할-정복 (Divide-and-Conquer)
- 큰 문제를 작은 하위 문제로 분할하고, 작은 문제를 해결한 후 결합하여 큰 문제를 해결
- 병렬로 문제를 해결할 수 있음
- 분할(Divide): 큰 문제를 더 이상 분할할 수 없을 때까지 재귀적으로 분할
- 정복(Conquer): 분할된 작은 문제를 해결
- 결합(Combine): 해결된 하위 문제들을 원래 문제에 대한 결과로 조합

퀵 정렬에서도 쓴 것!

## 백트래킹 (Back Tracking)
- 주어진 문제를 임의의 방법으로 해결하다가 실패하면 이전 상태로 돌아가며 다른 방법으로 해결
- "답이 될 수 없는 상황"을 정의하고, 답이 될 수 없으면 끝까지 수행하지 않고 즉시 종료
트리 구조에서 많이 이용됨

## 동적 프로그래밍 (Dynamic Programming)
- 복잡한 문제를 해결하기 위한 문제해결 방법으로, 큰 문제를 여러개의 작은 문제로 나누어서 해결
- 앞서 해결한 해들을 재사용
- 메모이제이션(Memoization): 동일한 계산을 반복해야 할 때, 이전에 계산한 값을 저장하여 재사용

예시) 동적 프로그래밍을 활용한 피보나치 수열 구하기
	- F(5) = F(4) + F(3), F(4)=F(3)+F(2)...
	- 한번 구해둔 F(x) 값을 저장해두었다가, 필요한 시점에 재사용

## 재귀 (Recursion)
- 함수가 자기 자신을 호출하여 문제를 해결하는 알고리즘
- 재귀함수는 반드시 종료 조건이 있어야 함
- 문제를 더 작은 단위로 나누고, 결과를 결합하여 문제를 해결
- 피보나치 수열 구하기: F(n) = F(n-1) + F(n-2)

세상엔 다양한 알고리즘 트레이닝 사이트가 있으니 이런 사이트에서 연습을 많이 해보는 것도 좋은 방법일 것
