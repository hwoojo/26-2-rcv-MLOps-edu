# 이론
## 변수?
- 변수란 데이터가 저장된 저장소를 이름 붙인 것
- 컴퓨터의 메모리에 저장됨
- 프로그래머가 정의되고 값을 할당할 수 있음
- 정해진 규칙으로 이름 붙일 수 있음
- 다양한 타입으러 저장되며, 타입에 맞는 연산을 수행할 수 있음

저장공간에 이름을 붙이는 것을 통해서 접근하는 형태
변수의 종류에 따라 다양한 연산이 가능

### 파이썬에서 변수
- 문자 또는 `_`로 시작해야 함 (3.6 이상 한글 변수명 지원... 하나 왜 쓰지)
- 특수문자 및 공백을 사용할 수 없음
- 대소문자가 구분됨 
- 미리 정의된 단어들은 사용할 수 없음
	- 뭐 True, and, as, def, 등등등...
	- 포함은 되는데 이걸 자체를 쓸 순 없다
### 선언 및 할당
- 타입을 지정하지 않음 (C와 달리)
- 늘 하듯 등호로 연결
- 홑따옴표 아님 쌍따옴표로 감싸서 문자열 할당

### 데이터 타입
- 숫자, Boolean, 문자열 등등
- Dynamic Typing - 자동으로 결정됨
- Type에 따라 사용할 수 있는 기능이 제한

### 변수에 이름 짓기
- 변수의 이름은 문맥에 맞게, 읽는 사람이 이해할 수 있도록
- 따라서 한 글자나 너무 길면 안 되고
- 단수와 복수를 구분해서 명명
- 카멜 케이스 (cameCase)와 스네이크 케이스(snake_case)를 통해서 표기하는데
	- 혼용하면 안 됨!
	- 그리고 파이썬은 스네이크 많이 씀 (관례적으로)
	- 그리고 이미 도구들이 다 스네이크로 많이 만들어져있어서

### 변수의 생명주기
- 정의된 변수는 정해진 생명주기를 가지고
- 변수의 선언과 초기화로 메모리에 할당
- 변수가 선언된 이후에 그 유효한 범위 내에서 사용이 가능하고
- 함수 종료, 새로운 값 할당, 변수 삭제 등으로 변수 파괴가 가능함
# 문자열 활용하기
- len(str)
- `str[3]` 등 인덱싱
	- 얘도 당연히 0부터 시작
- `str[0:3]`등 슬라이싱

관련 펑션들을 더 알아보자
- `count()` 글자 수 세기
- `find()` 특정 글자 위치 찾기 (없으면 -1)
- `index()` 특정 글자 위치 찾기, 없으면 에러
- `isalpha()` 해당 문자열이 알파벳으로 이루어져 있는지 확인
- `isdecimal()` 해당 문자열이 숫자로 이루어져 있는지 확인

파이썬은 문자열 만들기도 좀 이것저것 방법이 있는데
- 문자열 안에 변수 또는 값을 삽입
- % 연산자를 사용 ""%{format_code}
- format함수 사용: 문자열.format()
- 포멧 스트링(f-문자열) 사용하기 (Python 3.6)

1. 연산자 포메팅
	1. C언어 하듯이. %s, %d, %f 등으로 자리를 잡아주고
	2. 그 다음 뒤에 적기
	3. `"%d번째 당첨자는 %s입니다." %(number, string)`
	4. 좀 구식
2. Format 함수
	1. 문자열.format()으로 
	2. `"{0}번째 당첨자는 {1}입니다.".format(number, string)`
	3. 뭐야 뭔 차이야 싶긴 하기야 하겠는데 `{0}`을 재사용 가능함. 원래는 뭐 할 때마다 새로 적어주고 또 적어주고 해야 하는데
3. 포멧 스트링
	1. 3.6 이상
	2. `f"{number +1}번째 당첨자는 {string}입니다."`
	3. 가독성도 좋아지고, 변수명 및 연산 등을 중괄호에 넣어 다양한 형태로 활용 가능

# 자료구조 
이런 자료구조를 만드는데 중요한 건 연산 시간과 공간 활용을 잘 하는 것들을 일컫음
- 배열
	- 동일한 요소들이 나열된 자료형
	- 인덱스를 통해 특정 위치의 값을 지정할 수 있음
	- 연속된 메모리 공간에 할당
	- 문자열도 배열
- 연결리스트
	- 데이터 요소들을 노드라는 단위로 연결 및 저장
	- 노드는 데이터와 다음 노드를 가리키는 링크로 구성
	- 추가와 삭제가 용이하며 길이를 유동적으로 조절할 수 있음
- 스택
	- 순서를 가지는 자료형
	- LIFO, last-in-first-out, 후입선출 -> 최근 들어온 데이터 순서대로 조회
	- push and pop
	- 실행취소, 인터넷 방문 기록 등
- 큐
	- 순서를 가지는 자료형
	- FIFO, First-In-First-Out, 입력된 순서대로 조회
	- Enqueue, Dequeue
	- 줄서기, 예약 작업 등
- 해시 테이블
	- 키, 밸류로 구성되는 자료구조
	- 키를 별도의 연산(해싱)을 거쳐 특정 값으로 변환됨
	- 이에 대한 값 저장소가 1:1로 매칭 - O(1)
	- 키 충돌 문제가 발생할 수 있음
- 트리
	- 계층 및 분기 구조를 가지는 자료구조
	- Root(루트), parent / children (부모/자식)
	- 디렉토리 / 파일 구조
- 이진 트리
	- 자식 노드가 최대 2개로 구성된 트리
	- 이진 탐색 트리: 왼쪽 자식은 부모보다 작고, 오른쪽 자식은 부모보다 큼
	- O(logn)
	- 균형 잡힌 이진트리?

## 자료구조 선택의 기준
- 데이터의 종류와 형태
- 주요 연산의 종류
- 시간 복잡도와 공간 복잡도
- 애플리케이션의 활용 분야
- 효율성 및 성능

예시 1
- 데이터의 크기가 고정되어 있지 않음
- 데이터 중간에 새로운 요소를 삽입하거나 삭제하는 일이 잦음
- 데이터 외의 다른 정보들이 추가로 필요함
 연결리스트

예시 2
- 빠른 검색 결과가 필요함
- 파일과 디렉토리 구조와 같이, 게층화된 데이터 구조로 저장되어야 함
트리

예시 3
- 각 데이터에 매칭되는 키가 존재
- 데이터들 간에 키는 중복 사용되지 않음
- 매우 빠른 검색 속도가 요구됨
해시 테이블

예시 4
- 값이 들어온 순서대로 처리하고 싶음
- 처리된 데이터는 저장될 필요 없음
큐

## 파이썬 자료구조 리스트
1. 리스트
	1. 열거형 자료구조
	2. 순서대로 값을 저장
	3. 배열과 유사
	4. 자료형이 달라도 상관 없다
	5. 대괄호를 사용하고, 각 항목을 쉼표로 구분
	6. 요소들을 인덱스를 통해 접근 가능
	7. 문자열과 같이 슬라이싱도 가능
	8. 복합 리스트란 것도 있음
		1. 리스트의 요소로 리스트를 사용
		2. 가독성이 떨어지니까 사용하지 말 것
	9. 리스트 연산도 가능
		1. `[1,2]+['a','b']` # `[1,2,'a','b']`
		2. `[1,2] * 2` # `[1,2,1,2]` 
		3. 문자열 했던 거랑 비슷하게
	10. len, min, max도 가능
	11. 요소 찾기
```python
s = ['l','i','s','t']
s.index('i') # 1
't' in s # True
'x' not in s # True
s.count('l') # 1
```
추가: append(), 삽입: insert(), 확장: extend(), 요소 제거: del, remove(), 요소 꺼내고 제거: pop()
도 있다!


2. 튜플
	1. 열거형 자료구조
	2. 순서대로 값을 저장
	3. 배열과 유사
	4. 불변 속성 (변경을 가할 수 없음)
		1. 데이터가 선언 후 변경되지 않았다는 무결성을 가질 수 있음
	5. 기타 연산은 같다
	6. 패킹과 언패킹
		1. 패킹: 여러 값을 하나의 튜플로 (`tp=1,2,3`)
		2. 언패킹 : 하나의 튜플 값을 여러 변수로(`x,y,z = tp`)
		3. 언패킹 시 불필요한 값은 `_`를 통해서 생략할 수 있음. `x,_,_,y,z = (1,-1,0,2,5)`
		4. 언패킹 시 변수 중 하나에 `*`를  붙이면 남은 요소 전체를 리스트에 담아 대입함 
3. 딕셔너리
	1. 매핑 자료구조
	2. 키와 이에 해당하는 값으로 구성
	3. 해시 테이블과 유사
	4. 중괄호 `{}`를 사용하고 각 요소의 키와 값을 콜론으로 구분하고 요소 간에는 쉼표로 구분 
	5. `dictionary[key]`로 접근하면 됨
	6. key는 불변 타입만 
	7. value는 다양한 타입
	8. keys, values, items 메소드 있음 
	9. get, pop, key in dict... 같은 것으로 탐색 및 조작 가능
4. 세트
	1. 집합 자료구조
	2. 중복 불가능한 요소들로 구성
	3. 각 요소들이 해싱되어 저장, 순서를 가지지 않음
	4. 인덱스를 통한 요소 조회, 슬라이싱이 불가능함
	5. {} 또는 set()으로 정의
	6. add()로 세트에 값 하나 추가하기
	7. update()로 세트에 여러 값 추가하기
	8. remove()로 세트에 값 삭제하기
